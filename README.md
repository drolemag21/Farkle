# Farkle Table

Classic Farkle for 2 to 4 players, online, in the browser. Create a room, share the 4-digit code, and roll.

- First to 10,000 (Classic) or 5,000 (Speed). Set aside scoring dice, push your luck or bank; six scoring dice is hot dice.
- 3D dice that land the same way on every screen, a jazz-lounge soundtrack, and your choice of dice colour.
- Works on phones. No sign-up: players connect through Supabase Realtime.

**Play:** the GitHub Pages link for this repository (Settings → Pages).

The whole game is one file, `farkle-table.html`; `docs/index.html` is generated from it by `node tools/build-site.js`.
