How to Play

A full screen, not the scoring table alone. Turn flow first, then the points.

‹ MenuHow to Play

First to 10,000 wins. On your turn:

  1. Roll six dice.
  2. Set aside at least one scoring die.
  3. Roll the rest to push your luck, or Bank to keep the points.
  4. A roll with nothing that scores is a Farkle: the turn's points are gone.

Multiplayer

Three takes on the hosted room

Tapping Multiplayer creates a room right away. The risk: someone who came to join sees their own code first and sends it to the host. People who open an invite link skip the menu, so this only catches people typing a code, but the join option has to be visible without scrolling.

Recommendation: M1, with the name card from M3 on first visit

M1 keeps join visible with no extra tap, which matters most since joiners land here by default. Borrow M3's name card only when there's no saved name, so first-timers aren't introduced as "Player 42" and returning players skip it.

Build notes

  • Leaving the auto room. Join leaves the hosted room before joining, so a room nobody uses is dropped right away instead of sitting there.
  • Renaming in a live room. The network code can already re-send your player info, so editing the name on your seat updates everyone's screen.
  • Single Player gains a lobby. Today the bots button skips straight to the table; it would now use the lobby screen with the code hidden.
  • Rules move into lobbies only. The Classic/Custom cards leave home; the lobby's existing rules line takes over.
